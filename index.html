Photo Context Tagger

Tag any photo with context

Open photos… to pick individual photos, Open folder… to work through a whole folder, or drag photos or folders from Finder onto this window.

  • JPEG and PNG: the context is written into the photo file as standard XMP metadata (title, caption, keywords, people, location), so it travels with the photo. JPEGs also get every field as one readable summary in their comment fields (EXIF User Comment, Windows Comments, JPEG comment) plus the IPTC caption and keywords that Preview and Photos read.
  • HEIC, TIFF, WebP, RAW: a browser can't safely rewrite these, so the context goes in a standard .xmp file with the same name next to the photo (e.g. IMG_1234.xmp), the convention Lightroom and exiftool use.

Select one photo, or ⌘-click / shift-click a batch, fill in what you know, and press Save (⌘↩ saves and moves on). Chrome will ask before it lets this page change files.

Needs Google Chrome (or Edge). Nothing is uploaded; the page only reads and writes the files you choose. Photos inside the Apple Photos library can't be edited directly: drag them to a Finder folder first.
